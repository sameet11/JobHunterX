02 — Module Breakdown (LLD)
📡
Job Scraper
src/scraper/
  • BaseScraper abstract class — defines search(title, location)
  • NaukriScraper — Public JSON API at jobapi/v3/search
  • LinkedInScraper — Playwright + persistent profile dir
  • IndeedScraper — SerpAPI google_jobs engine
  • scraper_factory.get_scraper(source, config)
  • LocalDB.already_seen() dedup before scoring
Playwright SerpAPI httpx Pydantic
🧠
JD Analyzer
src/analyzer/jd_analyzer.py
  • Claude on Vertex via anthropic[vertex] SDK
  • Returns JDAnalysis: match_score, missing_skills, keywords_to_include
  • should_apply flag — orchestrator skips if False
  • UsageStats tracks tokens + cost per run
  • tenacity retry wrapper (3 attempts, exp backoff)
  • Default model: claude-sonnet-4-6
anthropic[vertex] tenacity Strict JSON
📄
Resume Tailor
src/resume/resume_tailor.py
  • Reorders Technical Skills by JD keywords_to_include
  • Zero hallucination — content unchanged, only order changes
  • Parses SKILLS_BLOCK markers in resume_template.html
  • Renders PDF via Playwright page.pdf() to output/
  • Filename: {company}_{role}.pdf (sanitized)
  • Falls back to static PDF on Playwright failure
  • Toggleable: user_config.use_tailored_resume
Playwright PDF Keyword reorder +15-20 ATS pts

Human Behavior
src/utils/human_behavior.py
  • random_delay() — Gaussian distribution, not uniform
  • type_text() — per-keystroke delay 50-150ms
  • human_click() — random offset, pre/post delays
  • read_and_pause() — ~200ms per word of JD
  • 5-15 min gap between applications
  • 10-20 min long break every 3rd app
playwright-stealth Gaussian Persistent context
🎯
Application Engine
src/apply/
  • LinkedInApplier — Easy Apply multi-step modal
  • NaukriApplier — Naukri quick apply flow
  • FormFiller — heuristic field classifier (label/aria/placeholder)
  • ScreeningQA — Claude on Vertex for unmapped fields
  • captcha_detector — detect → screenshot → console confirm (no DOM polling)
  • CAPTCHA policy: bot goes idle, human presses Enter, bot resumes with human pacing
  • DailyLimiter — caps at DAILY_LIMIT/day (default 15) via SQLite
  • ApplyResult: SUBMITTED | SKIPPED | FAILED | CAPTCHA | REDIRECT
Playwright async Claude on Vertex Pydantic

Approval Engine
src/outreach/approval_engine.py
  • 3 modes: INTERACTIVE | AUTO_APPROVE | AUTO_REJECT
  • CLI prompt: [A]pprove / [E]dit / [R]eject / [S]kip
  • Edit opens $EDITOR (or notepad on Windows)
  • Parses SUBJECT: line + body after edit
  • Status updates: DRAFTED → APPROVED | EDITED | REJECTED
  • Auto modes for CI / scheduled runs
stdin/stdout $EDITOR enum modes
📤
Email Sender
src/outreach/email_sender.py
  • BaseEmailSender abstract → send(message, attachment)
  • DryRunEmailSender — logs + stores in .sent list
  • SMTPEmailSender — Gmail SMTP via App Password (port 465 SSL)
  • Refuses if status != APPROVED/EDITED
  • Refuses if recruiter has no email
  • Attaches tailored resume PDF when configured
  • Returns SendResult(success, message_id, error)
smtplib Gmail App Password PDF attach
